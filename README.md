## 🌟 Overview
**BookFlow** is a premium, full-stack online book borrowing platform. It features a minimalist, high-contrast design that focuses on readability and user experience. Built with the latest **Next.js 15** and **BetterAuth**, it offers lightning-fast performance and industry-standard security.

---

## ✨ Key Features

### 🎨 Premium UI/UX
- **Minimalist Design:** Clean white aesthetic with bold typography.
- **Glassmorphism:** Modern backdrop blurs and subtle shadow effects.
- **Mobile Optimized:** Features a **2-column grid layout on mobile** for a premium "app-like" feel.
- **Interactive UI:** Smooth transitions, sticky navigation, and hover effects.

### 🔐 Advanced Authentication
- **Secure Sign-in:** Robust login and registration powered by **BetterAuth**.
- **Social Integration:** One-click **Google Login** support.
- **Session Management:** Persistent sessions with real-time profile data fetching.

### 📖 Discovery & Profiles
- **Smart Filtering:** Search books by title and filter by category instantly.
- **Dynamic Profile Management:** Users can edit their names and update profile picture URLs with ease.
- **Automated Avatars:** Integrated UI-Avatars for users without a custom profile picture.
